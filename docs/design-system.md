# Design System

## Colors
- Background: #f6f3ee
- Card background: #efe8df
- Border: #d8d1c7
- Text primary: #1f1a17
- Text secondary: #6b655f
- Primary button: #2a1d17

## Typography
- Hero headings should be very large
- Use clean sans-serif typography
- Body text should feel premium and minimal

## Layout Rules
- Use lots of whitespace
- Cards should be rounded-3xl
- Buttons should be pill-shaped
- Use generous section spacing
- Desktop sections can be 2-column
- Mobile sections should stack vertically
